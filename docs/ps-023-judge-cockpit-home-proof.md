## Smoke / validation script (canonical command)

PS-023 is validated by a single reusable, context-aware script:

```bash
python scripts/ps023_judge_cockpit_home_smoke.py
```

This is the canonical PS-023 validation command. It performs six static checks
and exits non-zero on any failure:

- `required_copy` — every required PS-023 phrase is present across the cockpit
  source files and this proof doc.
- `route_cta_check` — every route/CTA marker (`/passport/`, `/review`,
  `JudgeCockpitHome`, `judge-evidence-pack.md`, `docs/submission`, the GitHub
  remote) is reachable.
- `truth_boundary` — the project explicitly states ProofStudio does **not**
  prove semantic truth, legal authenticity, C2PA authenticity, or human
  authorship.
- `forbidden_claim_scan` — a **context-aware** scan. It rejects affirmative
  overclaims (e.g. `is C2PA verified`, `tamper-proof storage`, `Object Lock`,
  `enterprise-grade security`, `multi-user security`) only when asserted as a
  claim with no surrounding non-claim / negation context, and allows the same
  terms inside the truth boundary, the expanded non-claims hint, this proof
  doc's forbidden-claim section, and fenced scan commands. This corrects the
  prior validator drift that flagged honest non-claim documentation as an
  overclaim — that drift was a validator problem, not a product failure.
- `secret_scan` — the changed PS-023 files contain no API keys, tokens, bearer
  strings, or AWS/B2 credential literals.
- `proof_doc_check` — this proof doc records files changed, CTA, truth
  boundary, forbidden scan, typecheck, build, and this smoke script.

## Limitations / risks

- **No pinned golden demo run yet.** The `/passport/<run_id>` route is
  implemented (PS-019) but no run id is pinned on the home page, because no
  durable public run is currently guaranteed to be live on the public
  deployment. The home page exposes the route via a paste-run-id form instead
  of faking a pinned link. PS-024 ("Golden Demo Run Pinning") is the next
  slice and will resolve this.
- **External GitHub links** (`Open GitHub`, `View Evidence Pack`, `Read
  Submission Notes`) point at the configured `origin` remote
  (`https://github.com/GeorgeElArif/proofstudio`). These are honest
  references to existing repo paths. If the repo visibility changes, the
  links resolve to GitHub's standard not-found page rather than to a broken
  internal route.
- **No backend-driven content.** The home page is static copy grounded in
  prior proof docs; it does not fetch live evidence. Live evidence remains on
  `/review` and `/passport/<run_id>`.
