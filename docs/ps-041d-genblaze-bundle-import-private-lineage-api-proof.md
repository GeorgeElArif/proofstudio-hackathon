# PS-041D backend import and private-lineage proof

PS-041D is built from accepted ref `origin/accepted/proofstudio` at `78ee403f9da01571e5ebe88c96c7ee0635f54cf3`. Its pinned input is the MIT-licensed Backblaze sample `backblaze-labs/genblaze-gen-media-multi-provider-sample` at `2e31577b7a9d5a7b0309d814f2d0282088b33fe8`, parsed with the existing `genblaze-core==0.3.4` Manifest 1.5 models. No provider package was added or invoked.

The canonical bundle is `proofstudio.genblaze_bundle.v1`. Stage A is a standalone storyboard, B0/B1/B2 are three separate Genblaze Runs, and Stage C is external ffmpeg composition. B0→B1 and B1→B2 are recorded `parent_run` edges with `hash_covered=false`, because Manifest 1.5 excludes `parent_run_id` from its canonical hash. Stage A and scene-position relationships stay visibly inferred. Missing embedded evidence stays missing.

The normalized overlay uses six node kinds (`import_bundle`, `standalone_artifact`, `genblaze_run`, `manifest`, `asset`, `external_composition`) and nine edge kinds (`parent_run`, `generated_asset`, `external_input`, `storyboard_for`, `scene_member`, `composition_input`, `composed_output`, `manifest_for`, `embedded_manifest`). Campaign is scope, never a node. Steps remain ordered nested run summaries.

The boundary limits the index and each JSON object to 1 MiB, aggregate JSON to 16 MiB, objects to 256, relationships to 64, depth to 32, strings to 8 KiB, evidence identifiers to 256 characters, and notices to 4 KiB. It rejects invalid UTF-8, duplicate keys, non-NFC/control strings, strict-model extras, unsafe keys, credential fields, and signed/credentialed/private-target URLs. Raw prompts, provider payloads, upstream JSON, signed URLs, and transport URLs are neither stored nor returned.

B2 identity is structured as a server-authorized alias plus normalized relative key and optional version, size, type, opaque ETag, SHA-256, timestamp, prefix, and Manifest hash. ETag is never called SHA-256. The injected bounded reader is disabled by default, stays under one configured root, performs head-before-get consistency checks, and has list/JSON/asset/aggregate limits. Returned JSON crosses the same depth, NFC, control, credential, URL, aggregate-size, and strict role-model boundary as inline JSON. The V1 config has no unenforced timeout claim. Its tests use a fake backend only; normal import is inline fixture/metadata-only and uses no live B2.

The `ps041d.fingerprint.v1` identity uses canonical sanitized JSON computed by the importer. Descriptor `content_fingerprint` values describe normalized content. For recognized Genblaze Manifests, ProofStudio's normalized Run and Manifest content fingerprint includes recorded `run.parent_run_id`; Manifest 1.5 canonical hashes alone are insufficient source identity because they do not cover that lineage field. Verified canonical Manifest hashes remain safe metadata and `manifest_hash_verified` evidence checks, while absent and mismatched Manifest hashes still preserve `hash_present`, `manifest_hash_verified`, and `hash_mismatch` states without replacing normalized-content identity. A caller-declared `content_sha256` remains deterministic recorded evidence only, is never labeled verified without a byte check, and does not affect canonical bundle identity; the same declaration with changed inline content is a 409 conflict, while changing only the unchecked declaration is an idempotent no-op. Metadata-only B2 references use normalized key/version and do not claim checked bytes. Identity remains independent of campaign, timestamp, object/relationship order, transport URLs, raw prompts, and diagnostics.

The process-local typed conflict index covers descriptor objects, parsed Genblaze Run IDs, generated Asset IDs, and other supplied normalized node identities; it excludes the synthetic import-bundle source. Descriptor source-conflict fingerprints additionally bind semantic role as `sha256_json({"role": role, "normalized_content_fingerprint": descriptor_content_fingerprint})` under `("object", source_id)`. Run source-conflict fingerprints additionally bind B0/B1/B2 stage as `sha256_json({"stage": stage, "normalized_manifest_fingerprint": manifest_content_fingerprint})` under `("genblaze_run", run_id)`. The role or stage is deliberately not moved into the key. Reusing any typed upstream ID with different normalized content, a different descriptor role, a different Run stage, or another campaign is a safe conflict, including when the containing descriptor changes or the same Run ID records contradictory `parent_run_id` lineage. One source ID cannot silently change semantic role, and one Run ID cannot silently change B0/B1/B2 stage. Cleanup removes the campaign's complete typed index. One process-local lock rechecks constraints and swaps copy-on-write maps atomically; injected pre-commit failure exposes nothing and retry succeeds. Persistence, restart idempotency, and multi-worker safety are explicitly not claimed.

Mutation is only `POST /internal/operator/campaigns/{campaign_id}/genblaze-bundles`, protected by separate server-only `PROOFSTUDIO_IMPORT_OPERATOR_TOKEN` / `X-ProofStudio-Import-Token`. The PS-041C read token cannot import, and the operator token grants no account read bypass. Private FastAPI reads are `/internal/campaigns/{campaign_id}/import-bundles`, `/{bundle_id}`, and `/{bundle_id}/passport`.

The auth-server adds only authenticated reads at `/account/campaigns/{campaignId}/lineage`, `/{bundleId}`, and `/{bundleId}/passport`. Better Auth supplies account identity, active account↔campaign mapping authorizes owner/reviewer/viewer `proof.read`, and FastAPI rechecks exact campaign. The gateway recursively enforces exact nested keys, required fields, enum/hash/string/array bounds, per-kind primitive metadata, structured B2 references, enclosing campaign/bundle consistency, and detail node/edge membership across bundles, nodes, edges, run/step summaries, checks, limitations, details, and Passports. Extra URLs/prompts, signed nested references, malformed hashes/enums, and wrong nested scope return a whole-response safe 503. Absent, revoked, and cross-account reads converge on 404; proof dependency failures converge on safe 503. Redirects remain manual/fail-closed. No import token or mutation enters the gateway and no proof body or schema field enters Auth Postgres.

The private portable payload is `proofstudio.portable_lineage_passport.v1`. It deterministically carries normalized evidence, explicit/inferred classes, Manifest checks, B2 references, final-composition lineage, missing states, limitations, and: “ProofStudio reports what the imported pipeline record states; proof does not equal truth.” The exact public golden Passport and other public surfaces are unchanged.

Validation assets are the sanitized pinned-contract-derived fixture, focused Python parser/service/fake-reader/route tests, the non-recursive check-only feature smoke, and a disposable-Postgres real-session auth smoke. They record zero provider calls and zero live-B2 calls. PS-041E owns all dynamic UI, screenshots, visual evidence, and public presentation work.
