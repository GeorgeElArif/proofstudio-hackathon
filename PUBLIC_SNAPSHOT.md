# ProofStudio Public Hackathon Snapshot

This repository is a clean public submission snapshot of ProofStudio.

- Public application: https://proofstudio-web.onrender.com
- Verified GMI → Backblaze B2 proof: https://proofstudio-web.onrender.com/live-proof.html
- Interactive API documentation: https://proofstudio.onrender.com/docs
- Demo video: https://www.youtube.com/watch\?v\=awJsDzYsX-E

The public snapshot intentionally contains no private development Git history,
local environment files, deployment credentials, or service secrets.

ProofStudio proves what the recorded workflow and stored bytes show. It does
not claim semantic truth, legal authenticity, human authorship, C2PA
certification, or atomic create-if-absent storage.
