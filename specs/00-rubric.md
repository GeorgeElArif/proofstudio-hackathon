# 00 — Hackathon Rubric

ProofStudio is built for the Backblaze Generative AI Media Hackathon.

## Official judging criteria

1. Real-World Utility
2. Production Readiness
3. B2 Storage and Data Orchestration
4. Use of Genblaze

## Internal rule

No feature enters the MVP unless it clearly improves at least one judging criterion.

## Winning thesis

ProofStudio must not be a shallow generator. It must prove a production-minded AI media workflow:

Brief → pipeline → generated assets → B2 durable storage → manifest/provenance → verification → variant lineage → review/export.
