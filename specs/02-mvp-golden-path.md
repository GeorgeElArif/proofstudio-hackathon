# 02 — MVP Golden Path

## Judge-visible flow

1. User enters a campaign brief.
2. App starts a Genblaze pipeline.
3. UI shows Mission Control progress.
4. Pipeline generates at least one media asset.
5. Asset and manifest are stored in Backblaze B2.
6. UI shows a Provenance Passport.
7. User verifies SHA-256 / manifest status.
8. User regenerates a variant linked to the parent run.
9. User opens a Review Room and exports a campaign pack.

## MVP screens

1. Dashboard
2. Campaign Brief
3. Mission Control
4. Model Audition Board
5. Asset Detail / Provenance Passport
6. Variant Family Tree
7. Review Room / Export Pack
